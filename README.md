# Student-Realtor-Website

A clean, responsive front-end web directory built to help university students browse, compare, and explore off-campus housing listings, amenities, and rental rates.

🔗 **Live Demo:** [Student Housing Directory](https://cod3helios.github.io/Student-Realtor-Website/)

---

## Overview

Finding reliable student housing close to campus can be overwhelming. This project provides a lightweight, accessible listing interface where students can view available rentals, check key property features, and contact landlords or property managers. The repository now includes additional pages and client-side functionality to improve browsing and interaction.

## Key Features

* **Off-Campus Property Listings:** Organized cards detailing price, room counts, and location.
* **Amenity Overviews:** Highlights essentials like utilities included, furnished units, and campus distance.
* **Property Detail & Listings Pages:** Separate pages for browsing all listings and viewing individual property details.
* **Contact & About Pages:** Static pages with contact information and project/about details.
* **Client-side Interactivity:** Search, filtering, sorting, and simple UI interactions implemented with vanilla JavaScript.
* **Fully Responsive Design:** Adapts smoothly across mobile, tablet, and desktop viewports using CSS media queries and modern layout techniques.
* **Accessible & Lightweight:** Semantic markup and attention to keyboard and screen-reader accessibility, with no external framework overhead.

## Tech Stack

* **HTML5:** Semantic document structure for accessible navigation.
* **CSS3:** Custom styling, Flexbox/Grid layouts, and responsive breakpoints.
* **JavaScript (vanilla):** Client-side interactions, filtering, and dynamic UI behavior.
