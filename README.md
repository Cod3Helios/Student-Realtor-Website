# Student-Realtor-Website

A clean, responsive front-end web directory built to help university students browse, compare, and explore off-campus housing listings, amenities, and rental rates.

🔗 **Live Demo:** [Student Housing Directory](https://cod3helios.github.io/Student-Realtor-Website/)

---

## Overview

Finding reliable student housing close to campus can be overwhelming. This project provides a lightweight, accessible listing interface where students can view available rentals, check key property features (such as pricing, layout, and nearby conveniences), and reach out directly to property managers.

## Key Features

* **Off-Campus Property Listings:** Organized cards detailing price, room counts, and location.
* **Amenity Overviews:** Highlights essentials like utilities included, furnished units, and campus distance.
* **Fully Responsive Design:** Adapts smoothly across mobile, tablet, and desktop viewports using CSS media queries and modern layout techniques.
* **Lightweight & Fast:** Pure semantic markup and vanilla CSS with no external framework overhead.

## Tech Stack

* **HTML5:** Semantic document structure for accessible navigation.
* **CSS3:** Custom styling, Flexbox/Grid layouts, and responsive breakpoints.
